# Independent PolygonMesh cardinality review

The same frozen probe produced **64 passes / 96 failures before** and **160 passes / 0 failures after**, in both Debug and Release. Each run contains exactly 160 distinct `(case name, input transport)` outcomes. All 96 typed malformed candidate inputs return no document, and the baseline Debug dimension assertions no longer abort the process. Baseline Release could return a document with a malformed mesh retained or silently discarded; `published` records document return, not successful mesh registration.

The 160 outcomes comprise 52 positive controls, 96 typed malformed cases and 12 pre-existing raw signed-short overflow rejections. Positive cases include ordinary meshes, a 3×3 smooth control grid with distinct 4×5 fitting density, advisory POLYFACE counts, and two native ordinary mesh packet carriers. Every positive read is saved and reloaded in ASCII and binary. See `receipt.json` for hashes, category counts, provenance and exact limitations.

`Program.cs.txt` is the frozen probe source. `run_probe.py.txt` is the exact orchestration source used for all four final runs. `generate.py.txt` and `native_carriers.py.txt` explain fixture derivation; generated originals can contain producer timestamps, so the frozen DXF archive is authoritative. `frozen-inputs.tar.gz` contains exact input bytes and case definitions. Its case paths record the original scratch directory and need path-only relocation when replayed elsewhere. Compile `Program.cs` for .NET 8 against netDxf, then run the identical resulting probe binary beside each library under test. The runtime used here is .NET 8.0.15 and the compiler SDK is 8.0.408.

Native evidence covers the ordinary 3×4 POLYGONMESH `20F` from pinned TS1 AC1015 and AC1032 files. The carrier maps only the parent common owner from `1F` to `17`; surrounding resources and the sentinel LINE are generated. This independent probe checks grid shape and coordinate multiset through typed round trips. The module's separate native-packet provenance gate establishes the 14-packet transplant identity. Neither evidence extends to native smooth-surface regeneration or all POLYGONMESH payloads.
