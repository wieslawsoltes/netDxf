# Tenth mixed storage/editing regression

This regression connects complete native TABLE backing to explicit TABLEGEOMETRY editing, authored SECTION_MANAGER lifecycle, SECTIONSETTINGS source pointers, retained Polyface records, a declared-schema opaque neighbor, and affine explicit HATCH pattern editing. It checks actual shared identities and ordered reference release, together with immutable snapshots captured before editing or retirement.

The native carriers are the pinned `acad_table_simple.dxf` (R2013) and `acad_table_with_blk_ref.dxf` (R2018) fixtures already qualified by the stored table modules. Each is read through ASCII and binary input and saved through both transports. Native TABLE, TABLECONTENT, TABLESTYLE, TABLEGEOMETRY, CELLSTYLEMAP, and their actual STYLE/LTYPE dependencies remain part of the same document.

The Polyface, HATCH, SECTIONs, and opaque record are explicitly authored test data inside those native carriers. The Polyface source packet has one face physically before four coordinates, advisory header counts -17/123, and raw face slots 74=-32768, 72=0, 71=-1, 73=32767 in that order. The active fixed-slot face is [-1]; the later inactive values remain inspectable storage. This is synthetic grammar coverage, not an additional native Polyface producer claim. The `QUALIFIED_FUTURE_CURVE` opaque entity is likewise an explicitly declared schema packet with a flat 340 pointer to the actual face identity and no CLASS. It does not claim application geometry semantics or a native producer for that name.

The shared graph has TABLEGEOMETRY's first cell pointing to an explicitly created SECTION_MANAGER. Its ordered list starts [first, second, first] with the update flag set and is explicitly replaced with [second, first, second] with the flag cleared. Both SECTIONs own SECTIONSETTINGS that store [native CELLSTYLEMAP, actual Polyface face, null, actual face]. These source slots exercise the qualified generic pointer storage contract; they make no claim that a Polyface face or CELLSTYLEMAP is a suitable rendering input. The opaque entity independently points to the same face. The face carries authored XData 1005 pointing to the HATCH.

The test explicitly changes TABLECONTENT name and description plus its first qualified same-kind scalar and corresponding stored display text. Its native TABLE-owned style identity, all nonterminal references, all other scalar values, units and format flags remain unchanged; the TABLE packet is not implicitly synchronized or evaluated. The test edits the geometry's first-cell flags/dimensions/content width without allocating identities, then proves that the geometry guards manager erasure and the manager guards SECTION erasure. The HATCH receives a nonsimilar affine transform while its original pattern object remains unchanged. Clearing the geometry target permits explicit manager erasure while both SECTIONs remain registered. Erasing the first SECTION and replacing the second's source list with only CELLSTYLEMAP still leaves the opaque face pointer guarding the mesh. Removing the opaque entity releases that guard; the face's XData continues to guard HATCH until the entire mesh detaches. Finally HATCH removal succeeds. Old manager, geometry, pattern, opaque source-packet and diagnostic snapshots retain their captured values throughout this sequence.

Each of the eight profile/input/output combinations emits five lifecycle checkpoints (`input`, `linked`, `manager-erased`, `opaque-guard`, `released`) plus one atomic-failure/retry checkpoint. The failure case uses a foreign manager, duplicate creation, iterator-triggered erasure while the old geometry reference is still live, a collapsed HATCH transform, and a zero-output source-profile rejection before a successful retry. The mandatory gate requires all 48 files.

`tools/verify_tenth_mixed.py` reads physical packets in both transports. It checks complete native stored carriers, the geometry's exact declared edit slots, actual original manager/SECTION/settings/Polyface/opaque/HATCH identities and owners, explicit counts/order/nulls, CLASS counts, and absence of retired or replacement graph records. Native STYLE 11 follows only the pre-existing narrowly declared normalization: omit an empty group 4 and reorder public fields to the established writer order while preserving all values and trailing ACAD XData. Native LTYPE 14 and CELLSTYLEMAP packets remain exact. These two native TABLE common packets gain only the existing writer defaults 67=0, 62=256, 6=ByLayer, 370=-1, 48=1 and 60=0 in their established positions; their original layer, metadata, group 160 proxy length, proxy bytes/chunking and stored subclasses remain exact. The native TABLESTYLE common reactor and extension blocks swap order without any value change. The gate verifies those narrow source envelopes before applying either normalization.

The HATCH checks independently reconstruct its OCS plane, affine world-space family bases/offsets/directions and signed dash/gap/dot lengths, world boundary points, global pattern frame, and separate WCS Origin. Signed zero bits remain meaningful. The gate permits changes only to the individually checked affine fields and preserves the rest of the raw packet order and metadata.

Negative controls include parsed actual-output corruptions plus coherent ASCII-byte substitutions that rewrite all incoming pointers and HANDSEED consistently. The coherent substitutions must first pass independent ezdxf audit without errors or repairs, then fail the gate's original-identity or removal-inventory assertions. Replacing a removed manager, mesh, or opaque entity with a new valid identity is explicitly rejected by the expected lifecycle state.

Qualification is pending. No native CAD application execution is claimed.
