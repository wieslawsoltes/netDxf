# Ordinary PolygonMesh child records

An ordinary unsmoothed `PolygonMesh` loaded from DXF retains its physical `VERTEX` and `SEQEND` records. `PolygonMesh.VertexRecords` is a read-only view whose indices match the existing `Vertexes` array (`i + U * j`). `EndSequenceRecord` exposes the terminator. Each `PolygonMeshRecord` is registered under its actual source handle and exposes its structural owner, stored owner form, source profile, layer, linetype, XData, persistent reactors and extension dictionary.

DXF writes the mesh grid in a different order: `i` is the outer loop and `j` the inner loop. Both reading and writing map that physical order explicitly. Coordinate replacement through the existing array or `SetVertex`, transforms, and U/V closure changes preserve each slot's child identity and metadata. U and V remain immutable. Smoothed meshes continue through the existing geometry implementation and have no retained child-record view. Polyface meshes are outside this slice.

The supported ordinary packet has parent mesh flags 16, with optional U/V closure bits, no spline fitting and surface type zero; dimensions 2 through 256; exactly U×V child records with flags 64; and a following SEQEND. The reader requires one physical nonzero child identity and owner, the standard subclass sequence, and complete nonduplicated coordinates. It bounds every retained packet at 4,096 tags and shares the 1,048,576-tag aggregate budget with ordinary Polyline3D records. Private group contents and later private subclasses cannot supply a public identity, owner, coordinate or vertex flag.

A VERTEX's stored group 330 may name its actual containing POLYLINE or its actual containing BLOCK_RECORD. The structural `Owner` remains the mesh in both forms. SEQEND requires the actual containing POLYLINE. Both source forms are preserved, with the stored owner following an explicit same-document block move. A numeric handle matching a generated/default object does not establish source identity.

Optional common fields, vertex optional fields, private groups and subclasses, resource names, explicit null metadata groups, XData binary data, and ordered persistent reactors survive save/load. Resource renames follow the same resolved identities. Reactor and extension changes use the existing explicit metadata APIs. Owned graphs and incoming semantic references participate in mesh, containing-block, resource and object erasure guards. Arbitrary group codes 320–329 do not become dependencies. Removal does not invent a cascade through private or owned metadata.

Stored records are bound to their source document and DXF profile. A profile change or smoothing change is rejected before output. An original detached loaded mesh may return to its source document; adopting it into another document is rejected before destination mutation. A qualified clean clone has independent records with null handles and cloned safe resources/XData, then receives fresh identities on adoption into a matching profile. Records with private, external or owned dependencies require a complete graph mapping and cannot be cloned. Parent and containing-block clone checks run before clone callbacks. Ordinary default density zero and smoothing state are copied directly in the existing geometry clone, avoiding the former default-density setter failure.

Qualification uses the unchanged ordinary native mesh chains from the R2000 and R2018 field fixtures and twelve unchanged files generated by ezdxf 1.4.4 across six DXF profiles and both transports. Producer meshes have asymmetric 3×4 and 2×3 grids, common and private metadata, XData, reactors and child-owned dictionaries. The independent verifier compares decoded raw child packets and physical identity-to-coordinate order; ezdxf's audited object projection alone is insufficient because it may silently project the parent's layer or owner onto child objects. Source generators and SHA-256 manifests are committed with the tests. These fixtures demonstrate file interoperability and packet preservation, not execution of a native CAD application in this environment.
